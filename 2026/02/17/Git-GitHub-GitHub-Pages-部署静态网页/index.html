📌 Git + GitHub + GitHub Pages 部署静态网页笔记

✨ 一、概念基础

  • Git —— 本地版本控制工具
  • GitHub —— 在线托管 Git 仓库平台
  • GitHub Pages —— GitHub 提供的免费静态网站托管服务

GitHub Pages 支持发布纯静态网页，如 HTML / CSS / JS。

🧠 二、整体流程

  1. 在 GitHub 创建一个仓库
  2. 在本地初始化 Git 并提交代码
  3. 关联远程仓库
  4. 推送代码到 GitHub
  5. 在 GitHub Pages 启用 Pages
  6. 访问网站（上线）

🏁 五、在 GitHub 启用 Pages

  1. 打开仓库首页
  2. 点击 Settings（设置）
  3. 在左侧选择 Pages
  4. 在 Build & deployment 下：
    • Branch → main
    • Folder → / (root)
  5. 点击 Save

几分钟内 GitHub 会自动部署网站。
